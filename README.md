# Object Oriented Programming lecture notes,assignments

## How to run 


1. install jdk
2. install [intellij idea](https://www.jetbrains.com/idea/?ysclid=mj17u0ceud627954335)
3. open folder and then click run button

### compile code manually: 
```
javac index.java
```

### (online, not recommended)
Copy code, paste it to online java compilers such as  [onlinegdb](https://www.onlinegdb.com/online_java_compiler),
[programiz](https://www.programiz.com/java-programming/online-compiler/)
